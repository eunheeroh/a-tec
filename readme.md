# 에이텍(A-Tec) 연구소 홈페이지

> **AI로 가르치고, 디지털로 출판하다.**

## 📋 프로젝트 개요

에이텍(A-Tec) 연구소의 공식 웹사이트입니다. AI 교육, 디지털 출판, 콘텐츠 제작 분야의 전문 연구소를 소개하는 원페이지 웹사이트로 제작되었습니다.

### 브랜드 의미
- **A** — AI (인공지능)
- **T** — Teach (교육)
- **e** — e-Publishing (디지털 출판)
- **c** — Contents (콘텐츠)
- **연구소** — 전문성과 신뢰감 부여

### 대표: 노은희

## ✅ 구현된 기능

### 1. 페이지 구성
| 섹션 | 설명 | 네비게이션 앵커 |
|------|------|-----------------|
| 로딩화면 | 브랜드 로고 애니메이션 로딩 | - |
| 히어로 | 슬로건, 타이핑 효과, 파티클 배경 | `#hero` |
| 회사소개 | 연구소 소개, 통계 카운터 | `#about` |
| 브랜드 | A-T-e-c 각 글자의 의미 | `#brand` |
| 사업영역 | 6가지 핵심 사업 카드 | `#services` |
| 인사말 | 대표 노은희 인사 메시지 | `#ceo` |
| 포트폴리오 | 타임라인 형태의 성장 비전 | `#portfolio` |
| 문의하기 | 연락처 정보 + 문의 양식 | `#contact` |
| 푸터 | 회사 정보, 바로가기 링크 | - |

### 2. 인터랙션 & 애니메이션
- ✅ **로딩 스크린**: 브랜드 로고 + 프로그레스 바
- ✅ **타이핑 효과**: "디지털로 출판하다" → "콘텐츠로 혁신하다" → "세상을 연결하다" 순환
- ✅ **파티클 배경**: Canvas 기반 연결선 파티클 시스템
- ✅ **스크롤 리빌**: 섹션 진입 시 페이드업 애니메이션
- ✅ **카운터 애니메이션**: 통계 수치 카운트업 효과
- ✅ **네비게이션**: 스크롤 시 배경 변화, 활성 섹션 표시
- ✅ **서비스 카드 틸트**: 마우스 호버 시 3D 틸트 효과
- ✅ **브랜드 카드 글로우**: 마우스 위치에 따른 빛 효과
- ✅ **모바일 메뉴**: 햄버거 토글 (X 변환 애니메이션)
- ✅ **맨 위로 버튼**: 스크롤 시 노출

### 3. 문의 양식
- 입력 유효성 검증 (이름, 이메일, 제목 필수)
- 이메일 형식 검증
- 제출 시 로딩 상태 표시
- 성공/오류 피드백 메시지

### 4. 반응형 디자인
- 데스크톱 (1200px+)
- 태블릿 (1024px 이하)
- 모바일 (900px 이하)
- 소형 모바일 (480px 이하)

## 🛠️ 사용 기술

- **HTML5** — 시맨틱 마크업
- **CSS3** — CSS 변수, Grid, Flexbox, 애니메이션
- **JavaScript (ES6+)** — DOM 조작, Intersection Observer, Canvas API
- **Google Fonts** — Noto Sans KR, Outfit
- **Font Awesome 6** — 아이콘
- **RESTful Table API** — 문의 데이터 저장
